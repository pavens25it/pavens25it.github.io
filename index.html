01 — About

Thoughtful systems, built from fundamentals.

I am an Information Technology undergraduate at Kongu Engineering College, focused on developing clear, dependable software that addresses concrete academic, operational, and user-facing needs.

My work spans structured backend engineering and modern web interfaces—from Java applications utilizing JDBC, multithreading, and relational database schemas to component-driven React and Next.js storefronts written in TypeScript.

I approach software development through steady experimentation and practical problem-solving: modeling clean data constraints, verifying edge cases with automated tests, and iterating until both the underlying architecture and the user interface feel deliberate.
